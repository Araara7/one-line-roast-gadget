Entry for the [make.fun bounty "One-Line Roast: The Gadget You Use Every Day"](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

`main.py` writes one original funny line to `/output/entry.txt` — my Wi-Fi drops every time I join an important call, then reconnects the second I switch to my phone, like it was testing my loyalty. A roast of the most everyday gadget of all, with the punchline landing on the last word.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (UTF-8, 132 characters).
The program is deterministic: running it twice writes exactly the same bytes.
It needs no network access and no dependencies beyond Python 3 stdlib.
